# Native platform API

The canonical public guide has moved to
[Native platform API](features/native-platform-api.md).

This path is retained so existing links and bookmarks continue to work. The
feature guide documents only the native `/platform/v1` API implemented by this
repository: authentication, catalog and capability discovery, scoped commands,
SSE events and reconnect, authority boundaries, errors, limitations, and
qualification. Private downstream deployment details do not belong in the
public Keith repository.
