# Keith crate guide

This guide covers all 83 packages currently discovered from the workspace's
`apps/*` and `crates/*` members. Each entry gives the crate's role and
representative functions or APIs; the named APIs are examples, not an
exhaustive symbol list.

The shortest route through the architecture is: common contracts -> domain services -> runtime composition -> application entry points. Dependencies are intended to flow in that direction, with executable crates assembling the lower layers rather than library crates depending on applications.
